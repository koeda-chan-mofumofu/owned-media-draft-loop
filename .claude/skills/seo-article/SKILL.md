# SEO記事 下書き作成スキル

## 入力

- 狙うキーワード（複数可）
- 記事タイプ：集客記事／比較記事／収益記事のいずれか（`docs/editorial-policy.md` 参照）
- 記事の元になる素材（自分の経験、確認済みの一次情報、メモ等。`source/inbox/`、`source/approved/`）
- （あれば）競合記事の見出し構成メモ（`source/briefs/`）

## 記事タイプ別の方針

- **集客記事**：検索意図（悩み・知りたいこと）に答えることを最優先。CTAは関連記事・note・SNSへの誘導
- **比較記事**：比較対象の違いを公平に整理する。断定的な優劣表現は避け、選ぶ基準を提示する
- **収益記事**：ランキング・おすすめ形式が中心。アフィリエイトリンクは実際のURLを書かず
  `[要挿入:アフィリエイトリンク（商品名）]` のプレースホルダーにする（ASP登録・リンク発行は人間が行う）

いずれの記事タイプも、CTA（関連記事・note・SNS・アフィリエイトリンク等への誘導）は
記事末尾だけでなく、**記事内の複数箇所**（導入直後・主要セクションの後・まとめ、目安2〜3箇所）
に配置する。

## 手順

1. 検索意図の整理
   - キーワードから読者が知りたいこと・解決したい悩みを言語化する
   - 手動でのWeb検索で上位記事の見出し傾向を確認するのはよいが、有料APIなどによる自動収集は行わない
2. 記事構成（見出し）の設計
   - 記事タイプ（集客／比較／収益）に応じた基本構成を組み立てる
   - 差別化ポイント（自分の経験・独自の視点）をどの見出しに入れるか決める
   - 構成を `source/briefs/` に記録する
3. 本文執筆
   - ですます調で統一する（だ/である調は使わない）
   - 1文50字以下を目安に、段落は3行程度でまとめる
   - 各見出し（H2/H3）の直後に1〜3行のリード文を入れる（いきなり箇条書き・表に入らない）
   - 箇条書きを3つ以上連続させない（間にリード文か表を挟む）
   - 一人称の体験・観察を2箇所以上入れる
   - 目標文字数の目安：3,000字以上（テーマにより調整）
   - 重要な結論・数値・アクションにあたる語句は `**太字**` で強調する（目安10箇所前後）。
     強調のための強調（乱用）はしない
4. AI感排除チェック（該当箇所は修正する）
   - [ ] 「場合もあります」「可能性があります」など曖昧な結論のまま放置していないか
   - [ ] 「〜することが重要です」が3回を超えていないか
   - [ ] 文末表現（です/ます/でしょう/体言止め）が単調に連続していないか
   - [ ] 「これにより」を使っていないか
   - [ ] 「検討することをおすすめします」のような弱い言い回しを「してください」等に置き換えたか
5. メタ情報の下書き
   - タイトル案を3つ（30字目安、キーワードを含む）
   - メタディスクリプション案（120字目安）
6. セルフチェック（すべて通るまで修正）
   - [ ] `source/approved/` に根拠がない数値・固有名詞・日付・引用に `[要確認]` を付けたか
   - [ ] 誇張表現・断定しすぎる表現がないか（`docs/editorial-policy.md` の避けたい表現を確認）
   - [ ] 見出し構成が検索意図に対応しているか
   - [ ] 一人称の体験・独自性が入っているか
   - [ ]（収益記事の場合）アフィリエイトリンクを実URLではなく `[要挿入:...]` にしたか
   - [ ] CTAが記事内の複数箇所（目安2〜3箇所）に配置されているか
   - [ ] 重要な結論・数値・アクションが太字で適度に強調されているか（乱用していないか）
7. `output/draft/YYYY-MM-DD/記事スラッグ.md` に本文を、同ディレクトリに `titles.md`（タイトル案3つ）と `meta.md`（メタディスクリプション案）を保存する
8. イラストが記事に必要な場合、`docs/illustration-style.md` のスタイルガイドに沿って
   構図・プロンプト案を提案する。**実際の画像生成（クレジット消費）は人間の確認後に行う**。
   自動で大量生成しない

## 禁止

- 公開・送信はしない。下書き保存まで
- WordPress等外部サービスへの自動投稿・自動編集（内部リンク追加を含む）・自動削除は行わない
- APIキー・トークンを使った外部データの自動収集は行わない
- 根拠のない断定をしない
- 太字記号 `*` の乱用
